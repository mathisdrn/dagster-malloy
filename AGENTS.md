# AGENTS.md - dagster-malloy

`dagster-malloy` is an **unofficial** community integration library providing [Dagster](https://dagster.io) support for [Malloy](https://github.com/malloydata/malloy) semantic models and notebooks (`.malloy` and `.malloynb`).

### Practices

- Keep track of changes in [CHANGELOG.md](CHANGELOG.md).
- Push commits on `main` branch.
- Use `uv publish` to publish to PyPI.
